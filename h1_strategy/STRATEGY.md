# XAUUSD H1「六合一」背離順勢策略 — 規則與績效

> 資料：XAUUSD M15 2023/1/3 ~ 2026/10/9（MT5 匯出，broker 時間 = 紐約 + 7），合成 H1。
> 驗證：研究期 2023~2024 選條件，驗證期 2025~2026/10 照搬。
> 程式：`h1_six_divergence.py`（本文件的每一條規則都在程式裡，數字可用 `verify.py` 重現）。

---

## 1. 一句話
H1 價格突破前一個擺動高（低）點、同時出現背離時，**不做反轉，而是跟著突破方向做**；只做和日線趨勢、H1 EMA200 同方向的單。
六種背離各自獨立下單、每種只用 1/6 的風險（背離種類越多、部位越大）。停利 3R，32 根 H1 沒結束就平倉。

---

## 2. 指標定義（全部用 H1，由 M15 合成：每小時 開=第一根開、高=最高、低=最低、收=最後收、tick volume 加總、spread 取最大）
| 指標 | 定義 |
|---|---|
| ATR14 | 真實波幅 TR = max(高−低, \|高−前收\|, \|低−前收\|) 的 14 根**簡單平均** |
| MACD | EMA12(收) − EMA26(收)（只用 MACD 線；本策略沒有用到 MACD 背離） |
| RSI14 | Wilder：漲跌幅用 alpha = 1/14 的 EMA（adjust=False） |
| Stoch %K | 100 ×（收 − 14 根最低）÷（14 根最高 − 14 根最低），再取 3 根簡單平均 |
| CCI20 | TP =（高 + 低 + 收）÷ 3；(TP − SMA20(TP)) ÷ (0.015 × 20 根平均絕對偏差) |
| OBV | 累加 sign(收 − 前收) × tick volume |
| EMA200 | 收盤價 EMA（span = 200，adjust=False） |
| 日線 SMA50 | 每個 broker 日最後一根收盤的 50 日簡單平均 |

---

## 3. 交易規則（以做多 / 向上突破說明；做空完全鏡像）

### 3.1 擺動點與突破
1. **擺動高點 P1**：某根 H1 的最高價 = 左右各 3 根（共 7 根）內的最高價。要等右邊 3 根收完才確認。資料開頭 250 根不使用。
2. **回檔**：P1 之後、突破之前的最低點，必須比 P1 的高點低至少 **1 × ATR14(P1)**。
3. **第一根突破**：P1 確認後（P1 + 4 根起）、P1 之後 60 根內，第一根最高價 > P1 最高價的 K 棒。
4. **第二推**：從第一根突破起最多 10 根（且不超過 P1 + 60 根）；其中每根「創 P1 以來新高」的 K 棒都檢查背離。

### 3.2 六種背離（每種背離在同一個 P1 只取第一根成立的 K 棒，稱為訊號棒 t）
| 版本 | 條件 |
|---|---|
| **推進** | 第二推幅度 A2 < 第一推幅度 A1。A1 =（P1 高 − 第一推起點低）÷ 起點那根的 ATR；第一推起點 = 「上一個擺動高點 P0 與 P1 之間（最多往前 40 根）」的最低點。A2 =（t 高 − 第二推起點低）÷ 起點那根的 ATR；第二推起點 = P1 到 t 之間的最低點 |
| **速度衰減** | 第二推速度 V2 < 第一推速度 V1；V = 幅度 ÷ 從起點到高點的根數 |
| **OBV** | OBV(t) < OBV(P1) |
| **RSI** | RSI14(t) < RSI14(P1) |
| **CCI** | CCI20(t) < CCI20(P1) |
| **Stoch** | %K(t) < %K(P1) |

### 3.3 盤面過濾（兩個都要和交易方向相同；都在「進場那根的前一根」判斷，只用已收完的資料）
- **日線狀態**：前一個 broker 日的日收 > SMA50 且 SMA50 比 20 個交易日前高 → 多頭（只做多）；日收 < SMA50 且 SMA50 比 20 天前低 → 空頭（只做空）；其他 → 盤整（不做）。
- **H1 EMA200**：前一根 H1 收盤在 EMA200 之上 → 只做多；之下 → 只做空。

### 3.4 進場、停損、出場、部位
| 項目 | 規則 |
|---|---|
| 進場 | 訊號棒 t 之後 **4 根內**，價格突破 t 的最高點即成交（停損單；若開盤已跳過，用開盤價成交） |
| 取消 | 突破之前價格先碰到停損價 → 取消這個訊號 |
| 停損 | 第二推起點（回檔最低點）− 0.1 × ATR14(t)；且距離進場價至少 0.5 × ATR14(t) |
| 停利 | 進場價 + **3 ×** 停損距離（進場那根不算停利） |
| 時間出場 | 進場後第 **32** 根 H1 收盤平倉 |
| 同根同時碰停損與停利 | 算停損（保守） |
| 部位 | 每個版本每筆風險 **1/6 R**；同一訊號六個版本都成立 = 1 R |
| 同時持倉 | **每個版本一次只持有一筆**（六個版本最多同時 6 筆）；持倉中的版本出現新訊號 → 忽略 |
| 同一版本同一根有兩個訊號 | 同一根 K 棒同時突破兩個擺動點時，取**最近的擺動點**（停損放在最近的回檔低點） |
| 成本 | 回測每筆扣進場那根的點差；**沒有扣隔夜利息** |

## 5. 已知風險
1. **挑選偏差**：六個版本、盤面過濾、3R 都是在 2023~2026 同一份資料上比較後選出；實盤績效預期會較低。
2. **只有一段多頭**：2023~2026 黃金由約 1,800 漲到 4,000 以上；空頭只有約 160 天、空單 202 筆，做空的優勢尚未確認。
3. **獲利主要來自做多**：多 +64R、空 +8R；每筆約 0.12~0.14R 來自多頭漂移。
4. **趨勢轉折會連虧**：2026/7 底部橫盤、日線仍判定空頭，空單連續停損（−2.8R）。SMA20 過濾、最大停損、時間停損、月虧上限都無法有效處理。
5. **最近轉弱**：2026 年每筆期望最低，2026/7 起進入回撤。
6. **隔夜利息**：平均持有 35 小時（1~2 晚）未計入，請用券商實際 swap 重算。
7. **手數**：停損約 3 ATR，帳戶約 10 萬美元才能精確按 1% 分配；小帳戶只能用固定 0.01 手（含浮動回撤約 $2,500）。

## 6. 實盤操作流程
1. 每天開盤：確認日線狀態（前一天收盤 vs SMA50、SMA50 的 20 天斜率）。盤整 → 當天不做。
2. 每根 H1 收盤：
   - 更新擺動點（左右各 3 根）、ATR14、EMA200、RSI / Stoch / CCI / OBV。
   - 若這根是 P1 之後第二推的新高（低），檢查六種背離；成立的版本記下訊號棒 t。
   - 或直接執行 `python3 h1_six_divergence.py --data 最新的_M15.csv --signals` 列出目前有效的掛單。
3. 有訊號、該版本沒有持倉、日線狀態與 EMA200 都同方向 → 在 t 的高（低）點掛停損單，有效 4 根 H1。
4. 成交後設停損（回檔低點 − 0.1 ATR，至少 0.5 ATR）與 3R 停利；第 32 根 H1 收盤仍未出場就平倉。
5. 建議先用每版本 0.01 手模擬或小量實盤 2~3 個月，確認訊號與回測一致再放大。

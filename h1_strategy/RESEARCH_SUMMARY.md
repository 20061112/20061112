# 研究摘要：為什麼是這個策略

完整紀錄：`research_log/RESEARCH_README.md`（第一 ~ 三十二部分）；原始研究程式在 `research_log/original_code/`。
以下「第 N 部分」都指那份紀錄。所有測試都用 2023~2026 的 XAUUSD，研究期 2023~2024、驗證期 2025~2026/10。

---

## 1. 研究路線與結論
| 問題 | 結論 | 出處 |
|---|---|---|
| 背離能做反轉嗎？ | **不能**。MACD / RSI / Stoch / CCI / OBV、波動調整推進背離、速度衰減背離，8 種背離算法 × M5 / M15 / M30 / H1，樣本外都 ≤ 0；背離後價格平均是**延續**的，越明顯的背離越偏延續 | 第二十二、二十四部分 |
| 加波動狀態條件？ | 低 / 高波動、擴張 / 收縮、帶寬寬 / 窄，研究期與驗證期方向常相反，不穩定 | 第二十二部分 |
| 等指標拐頭（例如 RSI 10 → 12）再進？ | 比直接進場少虧，但 RSI、Stoch、CCI、MACD、OBV 都沒有正期望 | 第二十三、二十四部分 |
| 改做順勢？ | H1 有效、M30 偏弱、M15 / M5 無效 | 第二十三、二十七部分 |
| 為什麼多空不一致？ | 主要是 2023~2026 黃金多頭的漂移；扣掉漂移後，H1 多空的延續超額差不多 | 第二十四部分 |
| 加盤面過濾？ | 日線趨勢（SMA50 + 斜率）與 H1 EMA200 同向後，每年為正，做空也轉正 | 第二十五部分 |
| 哪些背離穩定？ | 推進、OBV、速度衰減最穩；速度衰減是唯一在 H1 與 M30 都每年有超額的 | 第二十五 ~ 二十七部分 |
| 獲利 vs 超額？ | 每筆約 0.12~0.14R 是漂移；扣掉後仍為正（推進、OBV 最明顯） | 第二十六部分 |
| 六個一起開？ | 每日損益相關 0.47；各 1/6 R 同時開比任何單一版本好（日 Sharpe 2.5 vs 1.7~2.1） | 第二十六部分 |
| 出場方法？ | 停利放大較好（3R > 2R > 1.5R > 1R）；追蹤停損、保本、跌破 EMA20、半倉都較差 | 第三十部分 |
| 回到 SMA20 之上停止做空？ | 幾乎沒有效果（底部橫盤時價格大多在 SMA20 之下） | 第三十部分 |
| 最大停損、時間停損、日 / 月虧損上限？ | 都沒有在研究期勝過「3R + 原停損」 | 第三十一部分 |
| 先前的定案版 A（IB 突破）？ | 真正樣本外（2023/8~2025/12）只剩 +0.08R、PF 1.09，只有做多有效 | 第二十五部分 |
| 其他舊策略（LONBRK、布林外軌反轉、紐約假突破…）？ | 2023~2025 樣本外全部 ≤ 0 | 第十部分（最後一節） |

## 3. 漂移本身也是策略（日線，1 倍名目，2023/4 ~ 2026/10）
| 策略 | 總報酬 | 最大回撤 | 2026 年 |
|---|---|---|---|
| 買進持有 | +75% | −28% | −6.8% |
| 日線狀態多空（SMA50 + 斜率） | +61% | −15% | +10.0% |
| 收盤在 SMA50 上多 / 下空 | +53% | −14% | +19.3% |

假設做多利息 −5%/年、做空 −1%/年。趨勢追蹤在多頭賺得比買進持有少，但回撤減半、2026 年下跌段能賺錢，可當作底倉（第二十五部分）。

## 4. 方法上的注意
- 所有條件都在同一份 2023~2026 資料上比較過，驗證期雖然照搬，仍有挑選偏差。
- 2023 年以前的資料完全沒有用過；那是最重要的下一個驗證。

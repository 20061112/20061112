# XAUUSD M15 前高/前低突破 —— 最終版（研究第二十二~三十二部分）

> 資料：XAUUSD M1，2023/6/1 ~ 2026/10/8。時間一律為 **broker 時間（= 紐約 + 7）**，交易日 = 01:00 ~ 23:59。
> 金額：**美元/盎司 = 下 0.01 手的美元**；R = 損益 ÷ 停損距離（每筆固定風險時，1R = 每筆風險金額）。
> 重現：`python3 part28_m15_filters.py && python3 part32_final_m15.py`
> 輸出：`final_m15_trades.csv`（實際下單）、`final_m15_signals.csv`（含沒下單的影子訊號）、`results_final_m15.txt`、`final_m15_equity.png`。

---

## 1. 原理

1. **Pivot / 前日價位本身沒有支撐壓力效果**（第二十二部分）：碰到 Pivot 後的反彈率不比隨機畫的線高。
2. **但「突破」有一點延續**：價格碰到前一根 K 棒的高點（或低點）後，略偏往突破方向走（第二十三~二十六部分）。
   - 小週期這個效果很小，停損太近時會被點差與雜訊吃掉；**停損放大到 2 倍 ATR15、RR 拉大**後才顯現（第二十七、二十九部分）。
   - 逆勢（碰前高做空）在所有週期都虧。
3. **效果幾乎全部來自「順日線趨勢」**：日線多頭時突破前高做多、空頭時跌破前低做空才有效；
   逆日線趨勢的突破是負的（第二十八部分）。所以規則的核心是 **用日線決定方向，用 M15 前高前低決定進場點**。
4. **回撤來自日線盤整期**（勝率掉到 20~25%、連續停損）。用 50 日均線斜率 + 策略自己的權益曲線濾網，
   在盤整期自動停手，總獲利 −25%、MDD −55%（第三十一部分）。

## 2. 規則

### 2.1 每天開盤前（用到前一日為止的日線）
| 名稱 | 計算 |
|---|---|
| SMA50 | 最近 50 個交易日收盤平均（含前一日） |
| SMA50 斜率 | 前一日的 SMA50 − 10 個交易日前的 SMA50 |
| ATR日 | 前 10 個交易日（最高 − 最低）的平均 |
| **今天的方向** | **只做多**：前一日收盤 > SMA50 **且** 斜率 > 0；**只做空**：前一日收盤 < SMA50 **且** 斜率 < 0；其他：**今天不做** |

### 2.2 每根 M15 K 棒（M15 以 01:00 為起點：01:00、01:15、…）
| 項目 | 規則 |
|---|---|
| ATR15 | 前 20 根 M15 的（最高 − 最低）平均 |
| 點位 | 做多日：前一根 M15 的**最高價**；做空日：前一根 M15 的**最低價** |
| 前提 | 這根 M15 **開盤在點位內側**（做多：開盤 < 前高；做空：開盤 > 前低） |
| 進場 | 這根 M15 內**第一次碰到點位** → 停損單在點位成交（做多 buy stop = 前高；做空 sell stop = 前低） |
| 時間 | 22:00 以後不開新單 |
| B 條件 | (點位 − 今日開盤) × 方向 ÷ ATR日 **> −0.17**（今天已經逆著方向走超過 0.17 日 ATR 就不做） |
| 停損 | 點位反側 **2 × ATR15** |
| 停利 | 點位順側 **3 × 停損距離**（= 6 × ATR15） |
| 收盤 | 沒碰到停損/停利 → **當天最後一根（23:5x）平倉**，不過夜 |
| 上限 | 同時持倉最多 **8 筆**（已持有 8 筆時新訊號略過） |

實際操作：每根 M15 開始時，若方向與條件符合，就在前高（或前低）掛一張停損單，停損/停利一起掛；這根 M15 結束還沒成交就刪單，下一根重掛新的價位。

### 2.3 權益曲線濾網（影子交易）
- 把**所有符合 2.1 + 2.2 的訊號**（含上限 8）都記成影子交易，算出每筆的 R。
- 依出場順序累加成「影子累積 R」，再算它**最近 50 筆的平均**。
- 新訊號出現時：**影子累積 R < 50 筆平均 → 只記錄、不下單**；否則下單。
- 停手期間一定要繼續記錄影子交易，才知道何時恢復。（明細 `final_m15_signals.csv` 的「影子累積R」「影子累積R的50筆均線」「實際下單」欄位）

### 2.4 部位大小
每筆固定風險：**口數 = 每筆風險金額 ÷ (停損距離 × 100)**。
例：帳戶 10,000 美元、每筆 0.1%（10 美元）、停損距離 7.5 → 0.013 手。
不要用固定口數：停損距離隨金價與波動變化很大（2023 中位數 3.7 → 2026 18.6 美元）。

## 5. 限制（請一定要看）

1. **規則是在同一段 2023~2026 資料上一步步找出來的**：A、B 用 2023/6~2024 選、2025~2026 驗證；但停損 / RR / 上限 / 斜率 / 權益濾網都看過全期結果。
   真正乾淨的驗證需要 2023 年以前（或 2026/10 以後）的新資料，參數不動直接跑。
2. **主要賺的是日線趨勢**：日線盤整的期間會連續停損（最長 58 連虧），權益濾網只能減少、無法避免。
3. **滑價**：每筆期望 +0.19R ≈ +1.5 美元/盎司；停損單在快市可能多滑 0.2~0.5 美元，每筆少約 0.03~0.06R。
4. **同時最多 8 筆、同方向**：實際曝險是 8 倍單筆風險，最壞情況（8 筆同時停損）一次 −8R。
5. 模擬用 M1 OHLC，同一根 M1 內的先後順序用 K 棒顏色推估；停損 2 ATR15 時不明的情況很少，影響小。

| | 建議 |
|---|---|
| 規則 | 第 2 節（A + B + 50MA 斜率 + 權益濾網，停損 2 ATR15、RR 3、上限 8） |

## 7. 每天的操作流程（實盤）

**開盤前（broker 01:00 前，用前一日日線）**
1. 算 SMA50、10 個交易日前的 SMA50、前 10 日 ATR日。
2. 前日收盤 > SMA50 且 SMA50 上升 → 今天**只做多**；前日收盤 < SMA50 且 SMA50 下降 → **只做空**；其他 → **今天不做**。
3. （可選）前日收盤離 SMA50 超過 3 個 ATR日（順方向）→ 今天新單用 0.01 口。
4. 看影子帳本：影子累積 R ≥ 最近 50 筆影子單的累積 R 均線 → 今天的訊號實際下單；否則只記錄。（盤中每有影子單出場就更新一次）

**每根 M15（01:00、01:15 …，22:00 後不開新單）**
1. 前一根 M15 的高（做多日）/ 低（做空日）= 點位；這根 M15 開盤必須還在點位內側。
2. 檢查：（點位 − 今日開盤）× 方向 ÷ ATR日 > −0.17；目前持倉 < 8 筆。
3. 掛停損單在點位；停損 = 點位反側 2 × ATR15（前 20 根 M15 波幅平均），停利 = 3 × 停損距離。
4. 這根 M15 結束沒成交就刪單，下一根用新點位重掛。
5. 每個訊號不論有沒有實際下單，都要記到影子帳本（成交價、停損、停利、結果 R）。

**收盤**：沒碰到停損 / 停利的單，在當天最後一根（23:5x）平倉，不過夜。

## 9. 補充（第四十六部分）
- **RR**：最終版流程下 RR 4 全期最好（0.02 口 +20,694、年獲利/MDD 1.49），但 2023~2024 較差；RR 3 前後兩段較穩。要穩用 RR 3，要多賺可改 RR 4。RR 5 以上在有影子濾網時變差。
- **滾動 IB 版本 A**：放到 2023~2025 的樣本外幾乎不賺（年獲利/MDD 0.13），組合不會比 M15 單獨好 → 不建議結合。
- **Pivot 算法**：Woodie P、CPR、DeMark P 這類「中軸」點位有穩定的小幅反彈效果，但扣成本後不足以單獨交易。

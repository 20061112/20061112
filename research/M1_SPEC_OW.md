# XAUUSD OW 策略 — M1 開單規格書

> 版本：2026-10-11（第四十九部分定案：OW + IB 寬度兩端篩選 + 2R 保本 + 依突破快慢分倉）。**之後所有研究與實盤都以 M1 觸發為準。**
> 用途：給 EA / 程式實作或手動執行用。所有時間 = **broker 伺服器時間（紐約 + 7，夏令時間跟著紐約切換）**。
> 回測對照：`part49_m1_final_trades.csv`（逐筆，M1 2024/9~2026/10）、`results_part49.txt`、`FINAL_STRATEGY_OW.md`。

---

## 0. 一句話
前一天的價值區（TPO 70%）之外、順著那一側、寬度正常（不太寬也不比平常窄太多）的 IB，**IB 結束後 3 小時內 M1 收盤突破 IB 邊 + 0.05 ATR 就進場**；停損在 IB 另一側，浮盈到 2R 移到保本，當天收盤全部平倉；越早突破下越大（0.03 / 0.02 / 0.01 手），同時最多 5 筆。

---

## 1. 資料與名詞
| 名詞 | 定義 |
|---|---|
| K 棒 | M1，用 **K 棒開盤時間** 標示（例：03:42 的 K 棒 = 03:42:00~03:42:59，收盤在 03:43:00） |
| 交易日 | broker 時間 01:00 開盤的第一根，到當天最後一根（約 23:58）。週一照做 |
| 前一交易日 | 上一個有開盤的交易日（週一的前一日 = 上週五） |
| ATR10 | 前 10 個交易日的日 TR 平均（**不含今天**）。TR = max(日高−日低, │日高−前日收│, │日低−前日收│)，日高低收用上面定義的交易日 |
| 點差 | 回測用每根 K 棒的 spread 欄位（點 × 0.01 = 美元）；實盤就是真實成交 |
| R | 進場價到初始停損的距離（美元 / 盎司） |
| 手數 | 0.01 手 = 1 盎司，損益（美元）= 價差 × 手數 × 100 |

## 2. 每天開盤前（01:00 前算好）

### 2.1 前一交易日 TPO 價值區（VAH / VAL）
1. 取前一交易日全部 M1 K 棒。
2. 每 **30 分鐘一個字母**：01:00~01:29、01:30~01:59、…（以 K 棒開盤時間的「分鐘 ÷ 30」分組）。
3. 價格格子 **1 美元**：格子 n = [n, n+1)。每個字母取該 30 分鐘的最高 H、最低 L，令 floor(L) 到 floor(H) 之間（含）每一格 +1。
4. **POC** = 次數最多的格子；若有多個並列，取最靠近整個價格範圍中間的那一格。
5. **70% 價值區**：從 POC 開始，目標 = 總次數 × 0.70。重複直到累積 ≥ 目標：
   - 上方 = POC 區上緣再往上 2 格的次數和；下方 = 下緣再往下 2 格的次數和（碰到邊界就只算剩下的）。
   - 上方 ≥ 下方 → 往上擴 2 格；否則往下擴 2 格。
6. **VAH = 價值區最上面那格的上緣（格子 + 1）**；**VAL = 最下面那格的下緣**。

> 範例：2026/1/27 → VAH 5098、VAL 5047、POC 5087.5。

### 2.2 今日 ATR10
依第 1 節定義，用前 10 個交易日計算。

## 3. IB（Initial Balance）
- 每天 **18 個 IB**，起點 02:00、02:30、03:00、…、10:30，每個長 **60 分鐘**。
  - IB(02:00) = 開盤時間 02:00~02:59 這 60 根 M1 的最高 IBH、最低 IBL；IB 結束時間 = 03:00。
- 資料缺漏：IB 內 K 棒少於 48 根（80%）→ 這個 IB 不做。

### 3.1 資格（OW 篩選）—— IB 一結束就判斷
| 方向 | 條件 |
|---|---|
| 只准做多 | **IBL > 前日 VAH**（整個 IB 在價值區上方） |
| 只准做空 | **IBH < 前日 VAL**（整個 IB 在價值區下方） |
| 其他 | 這個 IB 不做 |

### 3.2 IB 寬度篩選（第四十九部分加入）—— IB 一結束就判斷，兩條都要符合
| 條件 | 說明 |
|---|---|
| IB 寬（IBH − IBL）≤ **0.4 × ATR10** | 太寬的 IB 停損太遠，主要放大風險 |
| IB 寬 ≥ **0.6 × 前 20 個交易日、同一起點 IB 寬的中位數** | 比平常同時段窄 40% 以上 = 市場還沒動起來，假突破多 |
- 「前 20 個交易日」不含今天；同一起點（例如都是 02:30 起的 IB）。可用天數少於 10 天 → 這個 IB 不做（只影響剛開始的兩週）。
- 先做 3.1、3.2 篩選，再做 4.3 的去重：同一根 K 棒同方向若有多個 IB 確認，只在**通過篩選的 IB** 裡取起點最早的那個。

---

## 4. 進場

### 4.1 突破判斷
- 觀察窗：IB 結束起 **3 小時**（K 棒開盤時間在 [IB 結束, IB 結束 + 180 分) 之內）。
- 多方突破價 UP = IBH + 0.05 × ATR10；空方突破價 DN = IBL − 0.05 × ATR10。
- 從觀察窗第一根開始，找**第一根收盤 > UP 或收盤 < DN** 的 K 棒：
  - 若第一個發生的方向 = 3.1 允許的方向 → 進場。
  - 若第一個發生的是**反方向** → 這個 IB 作廢（不再等順向突破）。
  - 3 小時內都沒有 → 作廢。
- 用**收盤**判斷，盤中碰到不算。

### 4.2 進場價與時間
- 以**確認那根 M1 的收盤價**市價進場（實盤：該 K 棒收盤後立刻送市價單；回測延遲一根、多 1 美元滑價仍 PF > 1.7）。
- 進場時間 = 確認 K 棒收盤時間（開盤時間 + 1 分）。

### 4.3 去重與上限（依時間順序處理）
1. 同一根 K 棒、同方向有多個（通過 3.1、3.2 的）IB 同時確認 → **只開 1 筆**（停損用起點最早的那個 IB）。
2. 開單當下若已有 **5 筆** 未平倉 → 這筆不開（不排隊、不補單）。
3. 每個 IB 最多 1 筆；停損或保本出場後，同一個 IB 不再進場。

### 4.4 手數（依突破快慢）
延遲 = 進場時間 − IB 結束時間：
| 延遲 | 手數 |
|---|---|
| ≤ 30 分鐘 | **0.03** |
| 30 分鐘 < 延遲 ≤ 60 分鐘 | **0.02** |
| 60 分鐘 < 延遲 ≤ 3 小時 | **0.01** |

## 5. 出場（每筆獨立管理，無停利）
| 順序 | 規則 |
|---|---|
| 初始停損 | 做多 = **IBL**；做空 = **IBH**（下單時就掛在券商端） |
| 保本 | 從進場那根之後，只要某根 K 棒的最高價（多）≥ 進場價 + 2R（空：最低價 ≤ 進場價 − 2R），**從下一根起**把停損移到進場價。只移一次，之後不再移 |
| 收盤 | 沒被停損就在**當天最後一根 M1 收盤**平倉（約 23:58，必須在 broker 收盤前）；不過夜 |
| 跳空 | 開盤就越過停損 → 以開盤價成交（回測如此處理） |

> 保本出場的單會是 −點差 左右（約 −0.01R），不是正好 0。

## 6. 虛擬碼
```
每天 00:59:
    VAH, VAL = tpo_value_area(前一交易日 M1, 字母 30 分, 格子 1 美元, 70%)
    ATR = 前 10 交易日 TR 平均
    MED[s0] = 前 20 交易日起點 s0 的 IB 寬中位數（每個起點各一個；可用天數 < 10 → 無）
    ibs = []

每根 M1 收盤（bar = 剛收的那根，T = bar 開盤時間）:
    # 1. 管理持倉
    for p in 未平倉:                                   # 停損由券商端執行
        if not p.be and p.side*(極值(bar) - p.entry) >= 2*p.R:
            p.be = True; 修改停損(p, p.entry)          # 下一根起生效
    if bar 是當天最後一根: 全部市價平倉; return

    # 2. IB 結束 → 建 IB
    for s0 in 02:00..10:30 每 30 分:
        if T + 1 分 == s0 + 60 分:
            H, L = s0..s0+59 的最高 / 最低
            side = +1 if L > VAH else (-1 if H < VAL else 0)
            w = H - L
            if MED[s0] 無 or w > 0.4*ATR or w < 0.6*MED[s0]: side = 0     # 寬度篩選
            記錄今天 s0 的 IB 寬 w（給之後 20 天的 MED 用）
            if side != 0: ibs.append(IB(s0, H, L, side, end=s0+60分, active=True))

    # 3. 突破判斷（同一根 K 棒同方向只開一單）
    opened = set()
    for ib in ibs (依 s0 由早到晚), ib.active:
        if T >= ib.end + 180 分: ib.active = False; continue
        up = bar.close > ib.H + 0.05*ATR
        dn = bar.close < ib.L - 0.05*ATR
        if not (up or dn): continue
        ib.active = False
        dir = +1 if up else -1
        if dir != ib.side or dir in opened: continue
        if 未平倉筆數 >= 5: continue
        delay = (T + 1 分) - ib.end
        lots = 0.03 if delay <= 30 分 else (0.02 if delay <= 60 分 else 0.01)
        stop = ib.L if dir == +1 else ib.H
        市價開倉(dir, lots, sl=stop); 記錄 entry, R = |entry - stop|
        opened.add(dir)
```

## 7. 範例（2026/1/28，0.03 手）
| 步驟 | 數值 |
|---|---|
| 前日（1/27）價值區 | VAH 5098、VAL 5047；今日 ATR10 = 109.05 |
| IB 02:30~03:29 | IBH 5202.46、IBL 5163.05 → IBL > VAH → 只准做多 |
| 寬度 | 39.41 = 0.36 ATR（≤ 0.4）；前 20 天 02:30 IB 中位數的 1.57 倍（≥ 0.6）→ 通過 |
| 突破價 | 5202.46 + 0.05 × 109.05 = **5207.91** |
| 確認 | 03:42 的 K 棒收 5210.06 > 5207.91 → 03:43 以 **5210.06** 做多 |
| 延遲 | 03:43 − 03:30 = 13 分 → **0.03 手** |
| 停損 / R | 5163.05；R = 47.01 美元 |
| 保本 | 價格曾到 5304.08（+2R）→ 停損移到 5210.06 |
| 出場 | 23:58 收盤 5417.42：**+4.41R，0.03 手 +622 美元** |

其他例子：2026/3/23 08:32 空單（延遲 92 分 → 0.01 手），浮盈曾到 4.4R 後反轉，保本出場 −0.1 美元；2026/5/21 04:11 多單停損 −1R。

## 9. 實盤注意事項
1. **時區**：broker 時間必須是紐約 + 7（多數 GMT+2/+3 伺服器）。若不是，IB 起點、交易日切分、字母都要換算。
2. **夏令時間**：broker 跟紐約同步切換時不用改；若不同步，切換那幾週的 IB 時間會錯一小時。
3. **最後一根**：一定要在 broker 收盤前平倉（例：23:55 前送單更保險）；收盤前點差會變大。
4. **停損要掛在券商端**，不要只用 EA 監控；保本修改失敗要重試。
5. **資料缺漏**：IB 內 K 棒不足 48 根就跳過；前一天資料不完整（少於約 70% K 棒）也跳過今天。
6. **成本**：回測已扣點差；若帳戶另有手續費，每筆再扣（每筆多 1 美元成本回測仍 PF > 1.7）。
7. **不要加的東西**：停利、移動停損、週一以外的日期篩選、「收回 IB 就出場」——都測過且變差。

## 10. 已知限制
- M1 驗證期間 2023/6~2026/10（第五十部分）：2023 下半年 −0.15R、2024 上半年 +0.08R（區間盤打平、不大虧），2024 下半年起每半年 +0.14~+0.43R；全期 +15,962 美元、最大回撤 −1,690。
- IB 寬度篩選、分倉門檻是看過 2026 資料後選的；兩者都在 M1 2023/6~2025/12 通過驗證（全期突破快慢每筆 R：≤0.5h +0.37、0.5~1h +0.16、1~3h ±0.02）。
- 盤整期（日內來回、收在中間）會連續停損；盤整暫停規則（候選 G）在 2023~2024 無效，已放棄。
- 每季檢視：連續兩季每筆 R ≤ 0 → 暫停並重新研究。
- 其他候選改良見 `FINAL_STRATEGY_OW.md` 第 7 節。

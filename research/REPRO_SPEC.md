# XAUUSD 組合策略：重現規格書

這份文件給「在另一個環境從零重寫」用：每一條規則都寫到可以直接寫程式的程度，第 8 節列出每一步該對到的數字，`repro/` 資料夾有逐筆參考答案。
原始程式：`part56_noslip_layers_mtf.py`（M15）、`core_ib.py`（IB）、`part58_robust_opt.py`（組合）、`part61_reference_export.py`（產生參考答案）。

組合 = **策略一：M15 前一根高低突破（最終版）** + **策略二：IB 突破核心（2R 保本）**，兩者獨立運行，部位相加。

## 1. 資料與時間

| 項目 | 規格 |
|---|---|
| 檔案 | MT5 匯出的 M1，Tab 分隔：`<DATE> <TIME> <OPEN> <HIGH> <LOW> <CLOSE> <TICKVOL> <VOL> <SPREAD>` |
| 期間 | 2023-06-01 01:00 ~ 2026-10-08 13:50（`data/XAUUSD_M1_2023_2026.csv`） |
| 時間 | 券商伺服器時間 = 紐約時間 + 7（全年固定，跟著美國夏令時間一起變） |
| 點差 | `SPREAD` 欄 × 0.01 = 美元/盎司 |
| 交易日 | `day = (時間 − 1 小時)` 取日期；即 01:00 ~ 隔天 00:59 算同一天（實際資料每天 01:00 ~ 23:5x） |
| 日內分鐘 | M15 策略：`mins = (小時 − 1) × 60 + 分`（01:00 = 0）；IB 策略：`mins = 從當天 00:00 起算的分鐘`（01:00 = 60） |
| 剔除不完整的日子 | M15 策略：只保留 M1 ≥ 600 根的交易日（→ 860 天）；IB 策略：只保留 M1 ≥ 1000 根的交易日（→ 859 天）。剔除的日子整天不存在（也不進日線） |
| 數量 | 1 份 = 0.01 口 = 1 盎司；損益 = 每盎司損益 × 份數 |

> ⚠ 剔除日子這一步用到「那天總共有幾根」，嚴格說是事後資訊；實盤上等於「假日 / 半天不做」。重現時照做才能對上數字。

## 2. 策略一：M15 前一根高低突破（最終版）

### 2.1 K 棒
- M15：每個交易日從 01:00 起每 15 分一根（`period = day + floor(mins / 15)`），**跨日連續編號**（當天第一根的「前一根」是前一個交易日最後一根）。
- 日線：每個交易日 O = 第一根 M1 開、H = 最高、L = 最低、C = 最後一根 M1 收。

### 2.2 指標（全部只用過去）
| 名稱 | 定義 |
|---|---|
| 前高 / 前低 | 前一根 M15 的最高 / 最低 |
| ATR15 (`a`) | 前 20 根 M15 的 (高 − 低) 平均，**不含當根**（簡單平均，不是 TR、不是 Wilder） |
| 日 ATR (`atrd`) | 日線 (H − L) 的 10 日簡單平均（不是 TR） |
| `pc` | 前一日收盤 |
| `ma` | 日收盤 SMA50，取前一日的值 |
| `ma10` | SMA50 取 11 天前的值（= 前一日 SMA50 的 10 天前） |
| `atr` | `atrd` 取前一日的值 |
| `o` | 今天開盤（當天第一根 M1 開盤，進場時已知） |
| ATR 比 `volrel` | `atrd / atrd 的 60 日平均`，取前一日的值（前 60+ 天是 NaN → 視為不觸發） |
| 熵變化 `dent` | 見 2.5 |

### 2.3 事件（進場訊號）
對每一根 M15（第 k 根，從第 1 根起）：
1. `a` 必須有值且 > 0；這根 M15 的開始時間 < 22:00（`mins < 21×60`）。
2. 做多點位 `L = 前高`；做空點位 `L = 前低`。兩個方向各自獨立判斷。
3. 若這根 M15 的開盤已經在點位外（做多：開盤 ≥ L；做空：開盤 ≤ L）→ 這個方向跳過。
4. 在這根 M15 內，找第一根 **最低 ≤ L ≤ 最高** 且分鐘 < 23:00（`mins < 22×60`）的 M1 → 進場 M1 `i`，以 **L** 成交（停損單）。
5. 若 `i` 是這根 M15 的第一根 M1，且前一根 M1 收盤已在點位外（做多：前收 > L）→ 跳過。
6. 只取 2023-08-24（含）以後、日線指標 `pc/ma/ma10/atr` 都有值的事件。

→ 這一步得到 63,135 個事件（2023-08-24 起）。

### 2.4 方向篩選（side = +1 多、−1 空）
| 代號 | 條件 |
|---|---|
| A | `(pc − ma) × side > 0`（前日收盤在 SMA50 的順方向） |
| B | `(L − o) × side / atr > −0.17`（今天開盤到點位，逆方向沒有超過 0.17 日 ATR） |
| S | `(ma − ma10) × side > 0`（SMA50 10 日斜率同向） |

A+B+S 後 21,967 個事件。

### 2.5 ATR 熵變化
- 每根 M15 的 TR = max(高−低, |高−前收|, |低−前收|)（第一根的 NaN 當 0）。
- 熵 = 最近 20 根 TR（含當根）：`p_n = TR_n / ΣTR`，`ent = −Σ p_n ln p_n / ln 20`（p = 0 的項略過）。
- `dent = ent − 10 根前的 ent`。
- 事件用的是**進場那根 M15 的前一根**（已收完）的 `dent`。
- 門檻 `CUT = 0.015843`（常數；來歷：只扣點差的流程跑到 VOL 層之後、2023-08-24 ~ 2024-12-31 的交易 `dent` 的 80% 分位）。

### 2.6 單筆模擬
- 停損距離 `risk = 2 × a`；停損 `L − side × risk`；停利 `L + side × 3 × risk`（RR 3）。
- 不設移動停損；沒碰到就在**當天最後一根 M1 收盤**平倉。
- **進場那根 M1 的內部路徑**用 K 棒顏色推估：收 ≥ 開 → 開→低→高→收；收 < 開 → 開→高→低→收。從「點位所在的那一段」之後依序檢查有沒有先碰到停損或停利（碰到就在同一根出場）。
- 之後的 M1：找第一根碰到停損（做多：最低 ≤ 停損）與第一根碰到停利（最高 ≥ 停利）；早的那個出場；同一根都碰到 → 用該根的顏色路徑決定先後。成交價 = 停損價 / 停利價（不處理跳空，見第 7 節）。
- 成本：`淨損益 = (出場價 − L) × side − 進場那根 M1 的點差 − 滑價`（滑價 0 或 0.3 美元/盎司，每筆一次）。
- `R = 淨損益 / risk`。

### 2.7 依序套用的層（順序不能換）
所有事件先全部模擬成「影子單」，再依序：

1. **CAP 同時最多 8 筆**：依進場時間排序；對每筆，數目前「已保留、且出場時間 > 這筆進場時間」的單；< 8 才保留。
   注意：這一層數的是影子單（包含之後會被權益濾網擋掉的單）。→ 14,050 筆
2. **EQ 權益濾網**：以 CAP 後的單為影子帳本。按出場時間排序，`cum = R 的累加`，`ma = cum 的 50 筆簡單平均`（不足 50 筆為 NaN）。
   對每筆進場：`k = 出場時間 ≤ 進場時間 的最後一筆在排序中的位置`；若 `k ≥ 50` 且 `cum[k] < ma[k]` → 不做。
   → 7,492 筆（只扣點差）/ 7,159（扣 0.3）
3. **VOL**：`volrel > 2.2` 的日子不做（NaN 不擋）。→ 7,375 / 7,046
4. **ENT**：`dent > CUT` 不做（NaN 不擋）。→ 6,067 / 5,786
5. **DS 單日 −15R**：按進場時間，同一交易日內，「出場時間 ≤ 這筆進場時間」的已保留單的 R 合計 ≤ −15 → 不做。→ **6,049 / 5,767**

> 權益濾網用的 R 會因滑價不同而不同，所以兩種成本的筆數從 EQ 開始不一樣，這是正常的。

## 3. 策略二：IB 突破核心 + 2R 保本

### 3.1 指標
| 名稱 | 定義 |
|---|---|
| 日線 | 同 2.1，但只用 ≥ 1000 根 M1 的日子 |
| ATR10 | 日線 **TR**（含前收）的 10 日平均，取前一日的值 |
| 前日效率 `peff` | 前一日的 \|C − O\| / (H − L) |

### 3.2 IB 與進場
1. IB 起點 `s0` = 02:00、02:30、…、10:30（共 18 個），長度 60 分：`s0 ≤ 時間 < s0 + 60`。這段 M1 少於 48 根 → 跳過這個 IB。
2. `IB高 / IB低` = 這 60 分的最高 / 最低。突破線：多 `IB高 + 0.05 × ATR10`；空 `IB低 − 0.05 × ATR10`。
3. 觀察窗：IB 結束起 3 小時（`s0+60 ≤ 時間 < s0+240`），只看每個 M5 的最後一根 M1（分鐘 +1 能被 5 整除，例如 03:04、03:09）。
4. 該根收盤 > 多方突破線 → 做多；< 空方突破線 → 做空；哪個先發生做哪個（每個 IB 最多一個事件）。
5. 進場價 = 這根 M1 的**收盤**；點差 = 這根 M1 的點差；從**下一根 M1** 開始模擬。
6. 去重：依（進場時間, s0）排序，同一分鐘同方向只留一筆（最早的 IB）。
7. 前日效率 `peff > 0.633` 的日子不做。星期一照做。**不限同時持倉數**。

→ 2023-08-24 起 6,796 個事件，`peff ≤ 0.633` 後 **4,615 筆**。

### 3.3 出場
- 停損 = IB 另一側（多：IB低；空：IB高）；`risk = |進場價 − 停損|`。
- 逐根 M1（從進場下一根到當天最後一根）：
  1. 先查停損：碰到（多：最低 ≤ 停損）→ 出場，成交價 = min(開盤, 停損)（多單；空單鏡像）；第一根不做跳空調整。
  2. 再查保本：這根最高 ≥ 進場價 + 2 × risk（多）→ 從**下一根**起停損改成進場價（只往有利方向移）。
- 沒停損就以當天最後一根 M1 收盤出場。
- `淨損益 = (出場價 − 進場價) × side − 進場點差 − 滑價`；`R = 淨損益 / risk`。

## 5. 績效計算方式

| 指標 | 定義 |
|---|---|
| 日損益 | 依**進場日**加總（淨損益 × 份數） |
| 逐分鐘含浮虧 MDD | 每分鐘權益 = 已出場單的淨損益（記在出場那一分鐘）+ 在場單 (當分鐘收盤 − 進場價) × 方向 × 份數；取最大回撤 |
| 日結 MDD | 日損益累加後的最大回撤 |
| 年獲利/MDD | 總損益 ÷ 年數 ÷ 逐分鐘含浮虧 MDD；年數 = (最後一個交易日 − 第一個交易日) 天 / 365 |
| 訓練 / 驗證 | 2023-08-24 ~ 2024-12-31 / 2025-01-01 ~ 2026-10-08 |

## 6. 實盤需要的程式邏輯（與回測的對應）

| 回測 | 實盤 |
|---|---|
| M15 每根開盤時就知道前高、前低、ATR15、熵、日線條件 | 每根 M15 開盤時計算，符合 A/B/S、VOL、ENT、DS 且上限與權益濾網允許 → 在前高掛 buy stop、前低掛 sell stop，SL / TP 用點位算好；這根 M15 結束或 23:00 未成交就取消 |
| 權益濾網的影子帳本 | 每個訊號都要「紙上記錄」成影子單（即使沒下單），依影子單的 R 判斷；影子單也佔 8 筆上限 |
| IB | 每個 IB 結束後，在 3 小時內每個 M5 收盤檢查；突破 → 市價進場、SL 放 IB 另一側；浮盈到 2R 後移到成本 |
| 收盤 | 每天最後一根前市價平掉所有單（不過夜） |

## 7. 已知的假設與限制（重現時要知道）

1. **M1 內部先後**：用 K 棒顏色推估，不是 tick 資料。
2. **M15 進場與停損成交價**：回測以點位 / 停損價成交、不處理跳空。第六十部分把它改成跳空用開盤價、同一分鐘出場不算已知，總損益只少約 3%（`results_part60.txt`），所以照本文件的簡化版重現即可。
3. **熵門檻、0.633、0.17、2.2、−15R 等常數**：都是看過資料後選的；2023-08-24 ~ 2024-12-31 之外沒有乾淨的樣本外。
4. **滑價**：固定每筆 0.3 美元/盎司是假設；IB 在 2023~24 對成本很敏感。
5. **排序的同值**：同一分鐘出場的多筆單，權益濾網的 50 筆平均可能因排序方式不同而有極小差異（原程式用 pandas `sort_values` 預設排序）。

## 9. 在新環境還需要驗證的事（回測做不到）
1. **成交**：實際點差、滑價（目標每筆 ≤ 0.3 美元/盎司），停損單在跳空時的成交價。
2. **伺服器時間**：新券商是否也是紐約 + 7；不是的話所有時段（IB 02:00~10:30、22:00 / 23:00 限制、交易日切點）都要換算。
3. **報價差異**：不同券商的 M1 高低會不同，前高前低與 IB 會略有差，逐筆對不上是正常的，看統計量（筆數、勝率、每筆 R）是否接近。
4. **影子帳本**：實盤程式必須自己記錄所有訊號的影子結果（含沒下的單）。
5. **樣本外**：2026-10 之後的資料是真正的樣本外；建議先小部位跑 2~3 個月，與回測的每筆 R、勝率、出場比例比對。
